今天的開源動態沒有落在單一模型競賽，而是同時出現兩條清晰主線：本地可常駐的個人代理系統，以及走向產線化的生成式影像／影視流程。QwenPaw、AionUi 與 DeepSeek-Reasonix 同列高星，共同指向「自架部署、多通道連線、CLI 協作、可擴充技能」；Pixelle-Video 與 waoowaoo 則把短片與工業級影視流程產品化，ComfyUI 依舊是底層節點引擎。阿里 open-code-review 以混合管線加 LLM 做行級評論，Orama 把全文與向量搜尋塞進極小體積——基礎設施與治理同步升溫。本地助理已從聊天視窗，升級為可擴充的常駐工作系統；生成式影像也從單次工具，走向可排程、可替換、可量產的管線。

一、今天的趨勢

第一條洞察是本地代理完成度的躍升。過去一年，「個人助理」多半停在 Web Chat 或單一 CLI；今日高星專案則同時要求：可自架、資料在地、多通道（即時通訊與桌面／TUI 並行）、Skills／MCP 擴充，以及多代理並行。QwenPaw 把三層記憶、本地小模型免金鑰、沙箱安全與 Agent OS 寫進同一產品敘事；AionUi 則以桌面 Cowork 介面整合二十餘個 CLI 代理，強調 24/7 常駐協作；DeepSeek-Reasonix 把終端編程代理做到 prefix-cache 穩定、可長時掛機。方向一致：助理不再是對話玩具，而是工作系統。

第二條洞察是生成式影像的產線化。Pixelle-Video 以「輸入主題 → 文案 → 配圖／影片 → TTS → BGM → 成片」的全自動短片引擎降低門檻，並保留 ComfyUI／RunningHub 與直連 API 的原子能力替換；waoowaoo 則定位工業級影視全流程代理，從分鏡、角色一致性到合成。ComfyUI 仍是節點式擴散後端的事實標準，前端產品在其上封裝工作流與模板。重點不是又一個文生圖按鈕，而是可重跑、可批次、可嵌入既有內容產線的系統能力。

第三條洞察是基礎設施與治理同步升溫。open-code-review 來自阿里內部大規模驗證，強調確定性規則管線加上 LLM Agent、精準行級評論與多語言缺陷規則；Orama 則以極小體積在瀏覽器、伺服器與邊緣提供全文、向量與混合搜尋及 RAG／Answer 體驗。當代理能改碼、能產片、能連外部工具時，審查品質與檢索基礎設施就不再是可選項，而是落地門檻。

二、Top 8 工具

#1 agentscope-ai/QwenPaw（Score: 6.0，MCP）

可自架的個人 AI 助理，支援本地或雲端部署、多通道連線與 Skills／Plugins／MCP 擴充。核心賣點包括三層記憶（工作上下文、完整歷史、以 ReMe 驅動的自演化個人知識庫）、QwenPaw-Flash 本地小模型免 API Key、核心級沙箱與 Tool／File Guard，以及多代理並行與 ACP 編排。另有 Coding Mode 三欄 Web IDE、Console／TUI／桌面端，並可接釘釘、飛書、微信、Discord、Telegram 等通道。[[1]](https://raw.githubusercontent.com/agentscope-ai/QwenPaw/main/README.md)[[2]](https://github.com/agentscope-ai/QwenPaw)

評語：在今日「私人超代理」浪潮中完成度最高——部署、記憶、安全、擴充與多通道一次補齊，適合立刻落地當常駐工作系統，而非只做 demo。

#2 esengine/DeepSeek-Reasonix（Score: 5.0，AI Agent）

針對 DeepSeek 優化的終端原生 AI 編程代理，強調 prefix-cache 穩定、可長時掛機，單一靜態 Go binary、以 TOML 驅動 provider／工具／插件。支援 OpenAI 相容端點、執行器與規劃器雙模型分離會話、MCP 與 Extension Protocol，並有 Desktop 與 Context Engine 相關演進。[[3]](https://github.com/esengine/DeepSeek-Reasonix)

評語：給深度使用終端與 DeepSeek 生態的開發者；長會話成本與快取工程是差異化重點，適合當主力 coding agent 而非通用聊天殼。

#3 iOfficeAI/AionUi（Score: 5.8，AI Agent）

免費、本地、開源的 24/7 Cowork 桌面應用，整合 OpenClaw、Hermes Agent、Claude Code、Codex、OpenCode、Gemini CLI 等二十餘個 CLI 代理，強調代理在本機讀檔、寫碼、瀏覽與協作，而非單純聊天客戶端。[[4]](https://github.com/iOfficeAI/AionUi)

評語：把碎片化 CLI 代理收斂成統一桌面工作台，適合作為「多代理調度層」；若你已有多套 coding CLI，AionUi 的價值在協作介面與常駐節奏，而非再發明一個模型。

#4 alibaba/open-code-review（Score: 4.3，Developer Tool）

阿里開源的混合架構 AI 程式碼審查 CLI：確定性管線結合 LLM Agent，輸出精準行級評論，內建多語言規則集（NPE、執行緒安全、XSS、SQL injection 等），相容 OpenAI 與 Anthropic，並經內部大規模驗證後開源。[[5]](https://github.com/alibaba/open-code-review)

評語：治理向工具的代表作。適合接入 CI／MR 流程；混合架構比「整檔丟給大模型」更可控，規則可審、結果可定位，是團隊落地 AI review 的務實路徑。

#5 ATH-MaaS/Pixelle-Video（Score: 5.6，AI Video）

AI 全自動短視頻引擎：輸入主題即可自動完成文案、AI 配圖／影片、語音、BGM 與成片；支援 ComfyUI／RunningHub 工作流與 DashScope、OpenAI、Seedream／Seedance、Kling 等直連 API，並有數字人口播、圖生視頻、動作遷移等擴充模組。[[6]](https://github.com/ATH-MaaS/Pixelle-Video)

評語：短影音產線化的高性價比入口。模板與原子能力可替換，降低「會用模型卻不會剪片」的門檻；內容團隊可先從主題批處理驗證 ROI。

#6 Comfy-Org/ComfyUI（Score: 6.2，AI Image）

最強大的模組化擴散模型節點式 GUI、API 與後端，以 graph／nodes 組合工作流，持續承接新模型與 partner nodes，是開源影像生成生態的底層引擎。[[7]](https://github.com/Comfy-Org/ComfyUI)

評語：分數居高不下並非炒作，而是基礎設施地位。今日多數短片／影視上層產品仍會呼叫或匯出 Comfy 工作流；會 ComfyUI，等於握住產線的可程式化核心。

#7 waooAI/waoowaoo（Score: 4.0，AI Video）

定位工業級 AI 影視全流程生產代理平台，涵蓋從短片到劇情向流程，支援由文本生成分鏡、角色與場景並合成完整影片，強調可控的好萊塢式工作流敘事。

評語：與 Pixelle-Video 的「短片一鍵」互補，更偏角色一致性、分鏡與影視管線。分數相對較低反映產品成熟度與生態仍在爬坡，但方向對準高單價內容產製，值得持續觀察。

#8 oramasearch/orama（Score: 5.2，RAG）

可在瀏覽器、伺服器與邊緣運行的輕量搜尋與 RAG 引擎，支援全文、向量與混合搜尋，核心體積訴求極小（less than 2kb 量級敘事），並提供 Answer／Chat 體驗與豐富插件生態。[[8]](https://github.com/oramasearch/orama)

評語：代理與應用都需要「夠快、夠近、夠小」的檢索層。Orama 適合嵌入前端與邊緣場景，降低為了 RAG 就拉起重型搜尋叢集的成本。

三、今日首選

Best Pick：agentscope-ai/QwenPaw

選它不是因為單一功能最炫，而是因為「私人超代理」所需的模組在同一專案裡閉環：自架部署與資料主權、三層記憶與可編輯知識庫、本地 Flash 小模型免金鑰、沙箱與策略治理、Skills／MCP／插件市場、多通道觸達，以及多代理並行與 ACP。對個人開發者與小團隊而言，這意味著可以今天就裝起來，把排程摘要、多通道播報、文件處理與 Coding Mode 放進同一常駐實例，而不是東拼西湊五個半成品。

與 AionUi 相比，QwenPaw 更像「自有 Agent OS + 統一助理」；AionUi 更像「多 CLI 的桌面編排器」。與 Reasonix 相比，Reasonix 深耕終端編程與 DeepSeek 快取工程，QwenPaw 則覆蓋日常工作系統與通道運營。若你的目標是立刻落地一個可擴充的私人超代理，QwenPaw 在今日榜單中完成度最高、路徑最短。建議安裝後優先驗證：本地模型或既有 API、記憶寫回是否可搜、沙箱策略是否符合你的檔案邊界，再逐步接入 MCP 與排程任務。

四、評分方式說明

AI Radar 分數為編輯綜合指標，並非單純 GitHub Star。權重大致涵蓋：近期熱度與討論密度、功能完整度與可落地性、文件與工程品質、與當日趨勢主軸的契合度，以及風險與維護訊號。同一日榜單內分數用於相對排序，跨日不宜直接橫向比較。收錄以開源可查 repo 為主，評語反映當日觀察，不構成投資或採購建議。若專案處於早期測試或有明確風險註記，會在對應段落標示，請以官方 README 與授權條款為準。

結語與 CTA

本地代理與影像產線化同一天並列高星，說明開源重心已從「能不能生成」轉向「能不能穩定地為我工作」。若你只跟一項：先試 QwenPaw 當常駐助理；若你做內容：用 Pixelle-Video 打通短片管線，並保留 ComfyUI 作為底層。歡迎收藏本日 Radar，並把你實際落地的組合回饋給我們，下期繼續追蹤代理治理與影視工作流的交接點。
